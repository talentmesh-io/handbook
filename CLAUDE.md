# TalentMesh Handbook

Product documentation for the TalentMesh application.

## Structure
- `/adrs/` - Architecture Decision Records
- `/api-specs/` - OpenAPI and AsyncAPI specifications
- `/architecture/` - Application architecture documents
- `/business/` - Business requirements and cases
- `/data-model/` - Database schemas and data flow
- `/requirements/` - Functional and non-functional requirements
- `/technical/` - Technical specifications
- `/ui-ux/` - Design guidelines and patterns

## Conventions
- API changes require spec update first
- Business requirements link to user stories
- Cross-reference openova handbook for infrastructure concerns
